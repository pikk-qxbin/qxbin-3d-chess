# QxBin 3D Chess

Local two-player 3D chess with **QxBin** Binary Probability Matrix move suggestion.

## Features
- Full chess rules (chess.js)
- Legal move highlights
- **QxBin Suggest** — Edge-style superposition + collapse (biasⁿ / (1-bias)ᵐ)
- Drag to rotate board, mild auto-spin toggle
- Live move notation + PDF export
- iframe-ready for Wix / embeds

## Live
Open `chess_qxbin.html` or embed:

```html
<iframe src="https://pikk-qxbin.github.io/qxbin-3d-chess/chess_qxbin.html" width="100%" height="700" style="border:none;border-radius:12px;" allowfullscreen></iframe>
```
